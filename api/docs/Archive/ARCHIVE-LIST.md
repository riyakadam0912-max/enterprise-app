# Archive list

Purpose

This page lists the historical documents that were removed from the main documentation path and stored in the archive area.

Who should read this

This list is intended for maintainers and support staff who need to know where older implementation history lives.

Overview

The active documentation set now concentrates on current product guidance. Historical notes remain available in the archive for reference.

## Included archive material

- backend integration fix reports
- event listener implementation notes
- security and authentication root-cause studies
- frontend refactoring and duplication reports
- dashboard refactoring planning and completion summaries
- notification system implementation history
- older audit and implementation snapshots

## Archive rule

Archive documents are reference-only and should not be treated as the primary source for how the product currently works.
